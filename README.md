# CodeMax Internship – React Native To-Do App

## About the Project
This is a mobile To-Do application developed as part of my CodeMax Mobile App Development Internship using React Native and Expo.

The application helps users manage their daily activities and organize tasks efficiently.

## Features
- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Search tasks
- Filter tasks by category
- View total and completed tasks

## Technologies Used
- React Native
- JavaScript
- Expo
- VS Code

## Installation

1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Open the project folder:
   ```bash
   cd codemax-mobile-todo-app
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the application:
   ```bash
   npx expo start
   ```
